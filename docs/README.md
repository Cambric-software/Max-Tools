# Max Tools documentation

Everything except the root `README.md`, `SECURITY.md` and `LICENSE` lives here.

| Document | Read it when |
|---|---|
| [ROADMAP.md](ROADMAP.md) | You are deciding what to build next. Authoritative and ordered; shared verbatim with Digital Saver. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | You need the layer map, the tool registry, or how a screen is assembled. |
| [DEVELOPMENT.md](DEVELOPMENT.md) | You are setting up a machine, running the app, or adding a tool. |
| [TESTING.md](TESTING.md) | You are writing or debugging tests. |
| [STORAGE.md](STORAGE.md) | You are changing what the app persists or where it lives. |
| [CACHE.md](CACHE.md) | You are working on cached downloads, entries or cleanup. |
| [UPDATES.md](UPDATES.md) | You are touching the release/update channel. |
| [RELEASES.md](RELEASES.md) | You are cutting a release or rebuilding installers. |
| [ECOSYSTEM.md](ECOSYSTEM.md) | You are working on product discovery or the Cambric manifest. |
| [BRANDING.md](BRANDING.md) | You are changing an icon, a logo, or the download page mark. |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | Something fails and you want the known cause first. |

## Conventions

- One topic per file. If a document grows a second unrelated topic, split it.
- Procedures are numbered steps, not prose. Every step states its answer.
- Verify claims against the code before writing them down. If something is not
  known, say so rather than guessing.
- The root `README.md` is the front door; keep it short and link here.
